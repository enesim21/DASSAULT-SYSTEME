# Présentation du projet

Ce projet, réalisé en BUT Informatique 1re année à l'IUT Nord Franche-Comté, consiste à créer un site web présentant Dassault Systèmes.
Le site est composé d'une page d'accueil et d'une page par membre du groupe : histoire, solutions, secteurs d'activité, positionnement économique et enjeux écologiques.
Toutes les pages partagent le même menu et indiquent leur auteur en pied de page.
Le site est hébergé avec GitHub Pages.
